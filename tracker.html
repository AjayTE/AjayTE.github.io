Kilometer input

Includes a feature where users can input the number of kilometers they've run or walked today, and the data is securely stored in an SQL database, making it accessible for further use in a Django web application.

Analytics page

An analytics page that allows users to visualize their running or walking data via interactive graphs, where they can view weekly, monthly, or yearly stats, along with a comparison of the current period's distance against the previous one, all built with Python, HTML, CSS, and JS.
