Task Manager App

Overview

Developed a secure and intuitive Task Manager application for individual users, enabling efficient task tracking and management through authentication and a streamlined interface.

Dashboard / Task List

Displays all user tasks organized into categories: Todo, Doing, and Done. Each task includes title, description, status, and optional deadline. Features include task creation, editing, deletion, filtering by status, and a search function for efficient task management.

Task Creation & Editing

Provides a form for adding new tasks or updating existing ones, with input fields for title, description, status, and deadline, accompanied by save and cancel controls.

User Profile

Allows users to manage their account settings, update their password, and securely log out of the application, ensuring enhanced security and personalized control.

Technologies Used

Stack: React, Node.js with Express, JWT, RESTful API, localStorage/cookies, Docker.

Note: Final-phase preview. Client-specific features hidden for privacy reasons.
