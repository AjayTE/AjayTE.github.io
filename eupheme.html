Secure Login System

This feature provides a protected login environment for the website. User authentication is handled through a secure SQL database, ensuring encrypted password storage and safe data processing. The system guarantees professional and reliable access to members-only content.

Dynamic Calendar system

A fully functional calendar module allows events to be added, updated, or deleted in real-time. Built using PHP, Javascript and an SQL backend, the system ensures the event overview is always current, offering an interactive and user-friendly experience.

User Profile Management

Each user has a personalized account page where they can view and edit their details, such as their study program and Instagram handle. This enables straightforward profile customization and keeps member information up to date.

Member Directory

A dedicated member overview page displays profiles of all registered users within the association. Information such as study program, academic year, and social media links is presented in an organized and accessible way.

Technologies Used

Stack: HTML, CSS, PHP, SQL, Javascript, Apache.
